# 🔐 Simulación de Análisis de Phishing – SOC Nivel 2

## 📌 Descripción

Este proyecto consiste en una simulación práctica de análisis de phishing, desarrollada a través de una página web de una empresa ficticia.

El enfoque principal está basado en la ejecución simulada de un analista SOC de segundo nivel, donde se recrea el proceso de validación y análisis de un correo sospechoso utilizando una herramienta de análisis simulada.

> ⚠️ **Nota:** Este proyecto es completamente educativo y se ejecuta en entorno local.

## 🎯 Objetivo

Recrear un escenario realista donde un analista SOC Nivel 2:

- Recibe un posible incidente (correo sospechoso)
- Realiza un análisis más profundo
- Determina si el correo corresponde a un intento de phishing
- Genera una respuesta basada en el análisis

## 🧠 Contexto SOC Nivel 2

A diferencia del Nivel 1 (monitoreo y triage), este proyecto simula tareas de Nivel 2 como:

- 🔍 Investigación de eventos sospechosos
- 📊 Análisis de indicadores (simulado)
- 🛠 Uso de herramientas de análisis (simulación)
- ✅ Validación de incidentes de seguridad
